> 기능 번호는 [REQUIREMENTS.md](REQUIREMENTS.md), 진행 상황은 [PLAN.md](PLAN.md).

## 1. 방향

**"기차 창가 — 창밖으로 풍경이 흐르고, 일정은 그날 하늘색으로 물든다"** — 시안 E (2026-11-22 채택).
- 화면 위에는 기차 창문이 있고, 그 안에서 그날 풍경(바다 · 산 · 도시 …)이 옆으로 흐른다. 먼 층은 느리게, 가까운 층은 빠르게.
- 일정 카드는 시간대 하늘색으로 물든다 — 아침 · 낮 · 노을 · 밤.
- 앱을 켜자마자 "가는 중"인 느낌이 들게 한다.

**왜** — 사용자 기준은 "앱만 켜도 여행 가고 싶게"였다. 도구 쪽 넷(A ~ D)을 먼저 그렸는데 여행 느낌이 약해서 풍경을 쓰는 넷(E ~ H)을 더 그렸고, 그중 움직임으로 설렘을 주는 E를 골랐다. 색 · 글꼴 · 모양 · 움직임의 확정 값은 PC 화면까지 그린 뒤 이 문서 3 ~ 6장에 옮긴다(아직 없음).

**비교한 방향** (2026-11-22, [mockups/Directions.html](mockups/Directions.html) — 같은 일정 판을 여덟으로 그림. 고르지 않은 것도 비교용으로 남긴다)

| | 방향 한 문장 | 시각 언어 |
|---|---|---|
| A | **노선도** — 하루가 한 노선, 장소는 역 | 흰 바탕 · 굵은 노선 선 · 역 동그라미 · 날짜마다 노선 색 · 역명판 같은 이름 |
| B | **승차권** — 일정 카드 한 장이 한 장의 승차권 | 미색 종이 · 절취선 · 펀치 구멍 · 고정폭 숫자 · 빨간 도장 |
| C | **출발 안내판** — 바뀐 일정이 역 전광판처럼 넘어간다 | 검은 판 · 호박색 글자 · 깜빡이는 "변경 중" · 글자판 넘김 |
| D | **여행 수첩** — 같이 채워 가는 여행 수첩 | 줄 노트 · 손글씨 제목 · 마스킹 테이프 · 연필 점선 동선 |
| **E ✔** | **기차 창가** — 창밖으로 풍경이 흐르고, 일정은 그날 하늘색으로 물든다 | 기차 창문 틀 안에서 흐르는 풍경 · 카드 왼쪽 띠가 시간대 하늘색(아침 · 낮 · 노을 · 밤) |
| F | **여권** — 들르는 곳마다 입국 도장이 찍힌다 | 남색 표지 · 금색 글자 · 무늬 바탕 · 장소마다 잉크 도장(날짜 · IN) |
| G | **항공우편 엽서** — 하루하루가 멀리서 보낸 엽서 | 빨강 · 파랑 사선 테두리 · "Greetings from" 그림엽서 · 우표 · 소인 · 손글씨 메모 |
| H | **여행 잡지** — 펼치면 잡지 표지 같은 노을 풍경과 큰 도시 이름 | 큰 풍경 표지 · 세리프 큰 도시 이름 · 넓은 여백 · 큰 기울임 숫자 |

A ~ D는 2026-11-22 첫 비교, E ~ H는 사용자가 "앱만 켜도 여행 가고 싶게"를 기준으로 더 그려 달라고 해서 같은 날 더했다.

도구는 방향 다음이다 — daisyUI 테마는 여기 값으로 덮고, 움직임은 "언제 · 무엇이 · 얼마나"를 여기에 먼저 적은 뒤 JS 명령 · CSS · View Transitions · anime.js 중 무엇이 맡을지 정한다([decisions/0001](decisions/0001-elixir-phoenix-liveview.md)).

## 2. 화면 목록 (초안)

기능에서 나온 화면이다. 이름 · 나눔은 시안을 그리며 바뀔 수 있다.

| 화면 | 기능 |
|---|---|
| 가입 · 로그인 | F-01 |
| 내 여행 목록 · 여행 만들기 | F-02 |
| **일정 판** — 날짜별 카드, 동선, 멤버 얼굴 | F-03 · F-04 · F-06 · F-07 · F-08 · F-10 |
| 카드 상세 | F-03 · F-08 |
| 멤버 · 초대 | F-05 |
| 경비 · 정산 | F-09 |
| 준비물 | F-11 |
| 돌아보기 | F-13 |

화면은 한국어, 문구는 해요체 *(판단 — minor-stacks · pc-buildcheck와 같게, M0에서 다시 정해도 된다)*.

# 화면 설계

> **화면 목록 · 이동 · 화면별 규칙 · 색 · 서체 · 움직임 · 빈 상태 / 로딩 / 오류 · 문구를 적는 문서다.** 규격과 색의 단일 출처는 여기고, 그림은 [mockups/](mockups/README.md).
> 기능 번호는 [REQUIREMENTS.md](REQUIREMENTS.md), 진행 상황은 [PLAN.md](PLAN.md).

## 1. 방향

**"기차 창가 — 창밖으로 풍경이 흐르고, 일정은 그날 하늘색으로 물든다"** — 시안 E (2026-11-22 채택).
- 화면 위에는 기차 창문이 있고, 그 안에서 그날 풍경(바다 · 산 · 도시 …)이 옆으로 흐른다. 먼 층은 느리게, 가까운 층은 빠르게.
- 일정 카드는 시간대 하늘색으로 물든다 — 아침 · 낮 · 노을 · 밤.
- 앱을 켜자마자 "가는 중"인 느낌이 들게 한다.

**왜** — 사용자 기준은 "앱만 켜도 여행 가고 싶게"였다. 도구 쪽 넷(A ~ D)을 먼저 그렸는데 여행 느낌이 약해서 풍경을 쓰는 넷(E ~ H)을 더 그렸고, 그중 움직임으로 설렘을 주는 E를 골랐다. 색 · 글꼴 · 모양 · 움직임의 확정 값은 3 ~ 6장(2026-11-22, [mockups/Tokens.html](mockups/Tokens.html)에서 고름).

**비교한 방향** (2026-11-22, [mockups/Directions.html](mockups/Directions.html) — 같은 일정 판을 여덟으로 그림. 고르지 않은 것도 비교용으로 남긴다)

| | 방향 한 문장 | 시각 언어 |
|---|---|---|
| A | **노선도** — 하루가 한 노선, 장소는 역 | 흰 바탕 · 굵은 노선 선 · 역 동그라미 · 날짜마다 노선 색 · 역명판 같은 이름 |
| B | **승차권** — 일정 카드 한 장이 한 장의 승차권 | 미색 종이 · 절취선 · 펀치 구멍 · 고정폭 숫자 · 빨간 도장 |
| C | **출발 안내판** — 바뀐 일정이 역 전광판처럼 넘어간다 | 검은 판 · 호박색 글자 · 깜빡이는 "변경 중" · 글자판 넘김 |
| D | **여행 수첩** — 같이 채워 가는 여행 수첩 | 줄 노트 · 손글씨 제목 · 마스킹 테이프 · 연필 점선 동선 |
| **E ✔** | **기차 창가** — 창밖으로 풍경이 흐르고, 일정은 그날 하늘색으로 물든다 | 기차 창문 틀 안에서 흐르는 풍경 · 카드 왼쪽 띠가 시간대 하늘색(아침 · 낮 · 노을 · 밤) |
| F | **여권** — 들르는 곳마다 입국 도장이 찍힌다 | 남색 표지 · 금색 글자 · 무늬 바탕 · 장소마다 잉크 도장(날짜 · IN) |
| G | **항공우편 엽서** — 하루하루가 멀리서 보낸 엽서 | 빨강 · 파랑 사선 테두리 · "Greetings from" 그림엽서 · 우표 · 소인 · 손글씨 메모 |
| H | **여행 잡지** — 펼치면 잡지 표지 같은 노을 풍경과 큰 도시 이름 | 큰 풍경 표지 · 세리프 큰 도시 이름 · 넓은 여백 · 큰 기울임 숫자 |

A ~ D는 2026-11-22 첫 비교, E ~ H는 사용자가 "앱만 켜도 여행 가고 싶게"를 기준으로 더 그려 달라고 해서 같은 날 더했다.

도구는 방향 다음이다 — daisyUI 테마는 여기 값으로 덮고, 움직임은 "언제 · 무엇이 · 얼마나"를 여기에 먼저 적은 뒤 JS 명령 · CSS · View Transitions · anime.js 중 무엇이 맡을지 정한다([decisions/0001](decisions/0001-elixir-phoenix-liveview.md)).

## 2. 화면 목록 (초안)

기능에서 나온 화면이다. 이름 · 나눔은 시안을 그리며 바뀔 수 있다.

| 화면 | 기능 |
|---|---|
| 가입 · 로그인 | F-01 |
| 내 여행 목록 · 여행 만들기 | F-02 |
| **일정 판** — 날짜별 카드, 동선, 멤버 얼굴 | F-03 · F-04 · F-06 · F-07 · F-08 · F-10 |
| 카드 상세 | F-03 · F-08 |
| 멤버 · 초대 | F-05 |
| 경비 · 정산 | F-09 |
| 준비물 | F-11 |
| 돌아보기 | F-13 |

화면은 한국어, 문구는 해요체 *(판단 — minor-stacks · pc-buildcheck와 같게, M0에서 다시 정해도 된다)*.

일정 판은 기기마다 배치가 다르다(목업: 모바일 [Directions.html?d=E](mockups/Directions.html) · PC [Board.desktop.html](mockups/Board.desktop.html)).
- **모바일**: 창문 하나(고른 날짜의 풍경) → 날짜 칩 → 동선 띠 → 카드 목록. 날짜는 칩으로 바꾼다.
- **PC**: 날짜를 칸으로 나란히. 칸마다 창문 하나가 기차 옆면 띠 안에 이어지고(날짜 순서대로 풍경이 이어짐), 창문 오른쪽 위에 그 날짜를 보는 멤버. 오른쪽 패널에 정산 · 준비물 · 방금 바뀐 것.
- 카드 순서는 시간순 자동, 시각 없는 카드는 맨 아래 "시간 미정"([decisions/0004](decisions/0004-card-order-by-time.md)).

## 3. 색

라이트 · 다크 둘 다 둔다(목업 값에서 흐린 글자만 진하게 고침). 대비는 WCAG 상대 휘도로 [Tokens.html](mockups/Tokens.html)이 직접 계산한 값이다 — 본문 글자 4.5 이상.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `bg` | `#f2f0eb` | `#14171d` | 바탕 |
| `card` | `#ffffff` | `#1e232b` | 카드 · 패널 |
| `chip` | `#e5e2da` | `#2a303a` | 칩 · 태그 · 보조 버튼 |
| `line-soft` | `#dcd8ce` | `#2c323c` | 옅은 선 · 점선(추가 버튼 · 시간 미정) |
| `fg` | `#23262d` | `#eceef2` | 글자 — 카드 위 15.1 / 13.6 |
| `muted` | `#656a75` | `#9aa0ad` | 흐린 글자(메모 · 날짜) — 카드 위 5.4 / 6.0, 라이트 바탕 위 4.8. 목업 `#737884`는 카드 위 4.4라 바꿨다 |
| `train` | `#2f3a44` | `#0b0d11` | 기차 옆면 띠 · 창문 틀 · 주 버튼(라이트) |
| `train-2` | `#3a4652` | `#1a1f27` | 창문 안쪽 테두리 |

**날짜 색** — 노선 색 8개를 1일차부터 돌려 쓴다(9일차는 다시 1번). 날짜마다 둘이다: `line`은 선 · 역 점 · 카드 테두리 · "바뀐 카드" 번짐처럼 글자가 없는 곳, `ink`는 흰 글자를 올리는 날짜 칩 · 버튼. 목업 색에 흰 글자를 바로 올리면 여섯 색이 4.5에 못 미쳐서(노을 2.9 · 모래 2.9 등) 같은 색상 · 채도에서 밝기만 낮춘 `ink`를 따로 뒀다.

| 4 | 모래 | `#c98a1a` | `#9c6b14` | 4.64 |
| 5 | 라벤더 | `#8e5bb5` | `#8e5bb5` | 4.87 |

**시간대 띠** — 카드 왼쪽 6px 띠. 글자를 올리지 않는 장식이고, 같은 정보를 시각 숫자와 아이콘이 이미 보여 줘서 색에만 기대지 않는다(아침 · 낮 · 노을은 바탕과 대비 1.3 ~ 2.0).

**풍경** — 여섯 가지로 시작한다. 풍경 하나 = 모양 하나(먼 땅 · 가까운 땅 경로) + 색 다섯. 날짜마다 사용자가 고르고, 안 고르면 날짜 순서대로 돌려 쓴다 *(판단 — 고르는 화면은 M2 · M4에서)*. 다크에서도 같은 색을 쓴다(창밖은 낮이어도 된다).

모양 경로(SVG)는 목업 `Tokens.html`의 `FAR` · `NEAR`가 원본이고, 구현에서 컴포넌트로 옮기면 그쪽이 원본이 된다.

## 4. 글꼴

**Pretendard** 한 가족(2026-11-22 사용자 선택 — IBM Plex Sans KR · Gothic A1 · Gowun Dodum과 비교).
- 시각 · 금액 숫자는 `font-variant-numeric: tabular-nums`(폭 맞춤)로 줄을 맞춘다.
- 굵기: 본문 400, 이름 · 시각 · 금액 700, 앱 이름 800.
- 크기(목업 기준): 여행 이름 20 ~ 22, 칸 제목 17, 카드 이름 15 ~ 16, 본문 14, 메모 13, 작은 글자(칩 · 라벨) 11 ~ 12.
- 구현에서는 CDN이 아니라 글꼴 파일을 직접 내려 준다(어떻게 받을지는 M1에서).

## 6. 움직임

"언제 · 무엇이 · 얼마나"와 맡는 도구. 시스템 "동작 줄이기"(`prefers-reduced-motion`)를 켠 사람에게는 전부 멈춘다 — 풍경도 멈춘 그림으로.

| 무엇이 | 언제 | 얼마나 | 맡는 것 |
|---|---|---|---|
| 창밖 풍경 | 화면이 보이는 동안 늘 | 먼 층 46초 · 가까운 층 16초에 한 바퀴, 무한. 탭이 가려지면 브라우저가 멈춤 | CSS |
| 다른 사람이 바꾼 카드 | PubSub로 변경이 들어올 때 | 0.7초 — 날짜 `line` 테두리가 번졌다 사라지고 4px 내려앉음 | CSS 클래스(`Phoenix.LiveView.JS`) |
| "편집 중" 표시 | 다른 멤버가 카드를 열고 있는 동안 | 1.6초 주기, 투명도 1 → .55 | CSS |
| 날짜 · 화면 전환 | 날짜 칩 · 카드 → 상세 | 브라우저 기본 교차(약 0.25초), 카드는 같은 이름으로 이어짐 | View Transitions(`onDocumentPatch`) |
| 카드 옮기기 | 다른 날로 끌어 놓을 때 | 놓는 순간 새 자리로 미끄러짐 + "바꾼 카드" 효과 | View Transitions + anime.js 드래그(M4) |
| 동선 선 그리기 | 날짜를 처음 열 때 한 번 | 1.1초, 왼쪽 → 오른쪽 | CSS. 돌아보기(F-13)에서는 스크롤 연동 |

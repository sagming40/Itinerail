# 0002. 만들 것은 같이 짜는 여행 일정 — 국내 + 해외, 추상 동선, 경비 정산

- 상태: 채택
- 날짜: 2026-11-22

## 맥락

[0001](0001-elixir-phoenix-liveview.md) 스택의 칸을 **역할대로 다 쓰는** 아이디어를 원했다. 실시간 · LiveView · Ecto · 인증은 어느 아이디어든 쓰니, 쉽게 노는 칸을 기준으로 봤다 — Oban(예약 · 반복 작업), 메일, Zag 1순위 부품(날짜 선택 · 콤보박스 · 태그 입력), anime.js(드래그 · SVG 선 그리기), CSS 스크롤 연동, GenServer 여러 개 + 슈퍼비전.

## 결정

**같이 짜는 여행 일정** — 이름은 Itinerail(itinerary + rail).
- 국내 + 해외 여행을 다 지원한다.
- 동선은 실제 지도 대신 노선도 스타일의 추상 동선으로 시작한다.
- 경비 정산을 넣는다(보여 주기만, 송금은 안 함).
- 여행마다 GenServer 하나가 동시 편집을 줄 세워 받는 구조로 푼다(CRDT 없음) *(판단 — M3에서 확인)*.
- 기능 · 범위는 [REQUIREMENTS.md](../REQUIREMENTS.md), 칸별 쓰임은 [PLAN.md](../PLAN.md) 1장.

## 검토한 대안

- **예약하는 몰입 방**(같이 도는 타이머 + 세션 예약 + 한 달 회고): 매일 쓸 것이지만 덜 화려하다.
- **보드게임 + 토너먼트**: OTP가 가장 깊지만 규칙 설계가 프로젝트 하나만큼 크다.
- 실시간 퀴즈 · 투표 방(작다), 오늘의 시드(크다), 만료 레이더(실시간이 없다).
- 사용자가 "여행 도메인은 해 본 적이 없다"며 이 안을 골랐다.

## 감수할 것

- 장소 검색에 외부 API가 필요하다 — 할당량 · 약관 · 장애([0003](0003-place-search-providers.md)).
- 동시 편집 충돌 처리가 어렵다. M3 완료 기준을 "두 브라우저 동시 옮기기 재현"으로 못 박았다.
- 해외 여행이라 시간대 · 통화가 섞인다(REQUIREMENTS 4장).

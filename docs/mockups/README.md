# mockups — 화면 목업

> [DESIGN.md](../DESIGN.md)의 결정을 그림으로 보여 주는 참고 자료다. 규격 · 색의 단일 출처는 DESIGN이다.

## 보는 방법
- 파일을 더블클릭해 브라우저로 연다(파일 하나짜리라 `file://`로 열리게 만들었다). 글꼴은 CDN으로 불러와서 인터넷이 필요하다 — 목업이라 CDN을 쓰고, 실제 구현은 글꼴 파일을 직접 내려 준다.
- 2026-11-22 확인은 로컬 정적 서버(`http://127.0.0.1`)로 했다. `file://` 더블클릭은 아직 확인하지 않았다 — 안 뜨면 그때 서버로 연다.

**주소 파라미터** (`Directions.html`) — 없으면 네 방향을 나란히 놓은 보드

| 파라미터 | 값 | 뜻 |
|---|---|---|
| `d` | `A` ~ `H` | 그 방향 하나만 크게. 오른쪽 아래 검은 막대로 방향 · 다크를 바꾼다 |
| `dark` | `1` | 다크(C는 원래 어두워서 같다) |
| `edit` | `0` | "○○ 편집 중" 표시 끄기 |

화면 안에서: 날짜 칸을 누르면 날짜가 바뀌고(노선 색이 바뀜), "옮기기 데모"는 다른 멤버가 카드를 옮긴 것처럼 순서를 바꾼다(View Transitions). **같은 날 안에서 순서를 바꾸는 이 데모는 옛 안이다** — 하루 안 순서는 시간순 자동으로 정했다([decisions/0004](../decisions/0004-card-order-by-time.md)). 기준은 `Board.desktop.html`.

**주소 파라미터** (`Board.desktop.html`) — `dark=1` · `edit=0`. 오른쪽 아래 막대에 다크 · 편집 중 표시 · 모바일(E)로 가는 링크. 오른쪽 패널의 "옮기기 데모"는 다른 멤버가 카드를 다른 날로 옮긴 것처럼 바꾸고 "방금 바뀐 것"에 한 줄을 더한다(한 번 더 누르면 되돌림). 옮긴 카드는 그 날의 시간순 자리로 들어가고, 시각 없는 카드는 맨 아래 "시간 미정"에 모인다(0004, 3일차 '기념품 가게'). 1440 × 900 기준으로 그렸고, 가로 1100px보다 좁으면 가로 스크롤이 생긴다.

## 파일
| 보드 · 화면 | 파일 | DESIGN 절 | 채택 |
|---|---|---|---|
| **디자인 값 고르기** — 글꼴 넷 · 날짜 색 8개(line / ink, 흰 글자 대비를 페이지가 직접 계산) · 바탕 · 글자 · 시간대 띠 · 풍경 여섯(새로 셋) · 모서리 · 깊이 · 움직임 표(다시 보기 버튼). `dark=1` | `Tokens.html` | 3 ~ 6장 | **고름** (2026-11-22): 글꼴 Pretendard · 날짜 색 8개 line / ink · 풍경 여섯 다. 확정 값은 DESIGN이 원본 |
| **일정 판 PC** — E 방향. 날짜를 칸으로 나란히, 칸마다 그날 풍경이 흐르는 창문(기차 옆면), 칸 위 미니 노선, 시간대 하늘색 카드 띠, 오른쪽 패널(정산 · 준비물 · 방금 바뀐 것) | `Board.desktop.html` | 1장 | E 방향의 PC 안 (2026-11-22 그림) |
| 방향 비교 — 일정 판(모바일) 한 화면을 여덟 방향으로. 도구 쪽 A 노선도 · B 승차권 · C 출발 안내판 · D 여행 수첩, "여행 가고 싶게" 쪽 E 기차 창가 · F 여권 · G 항공우편 엽서 · H 여행 잡지 | `Directions.html` | 1장 | **E 채택** (2026-11-22). 모바일 E는 `?d=E`. 나머지는 비교용 |

E ~ H는 위에 날짜마다 바뀌는 풍경 그림(1일차 바다 노을 · 2일차 산 아침 · 3일차 도시)이 있다. E는 풍경이 창밖처럼 옆으로 흐른다.

예시 데이터는 지어낸 것이다(여행 이름 · 일정 · 멤버 · 금액).
